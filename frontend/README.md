# Segment Todo frontend

## Project setup

```sh
npm ci
```

### Compiles and hot-reloads for development

```sh
npm run dev
```

### Compiles and minifies for production

```sh
npm run build
```

### Lints and fixes files

```sh
npm run lint
```

The development server proxies `/api` and Socket.IO to the backend at
`http://127.0.0.1:3000`.
